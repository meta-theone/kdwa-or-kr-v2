# 한국신체장애인복지회 홈페이지 개선 시안 (버전 2)

기존 홈페이지(kdwa.or.kr)의 **원본 골격을 그대로 유지**하고, 지부·지회 관리 기능을 얹은 개선 시안입니다.
원본 정적 복제본(1차)은 별도 저장소 `kdwa-or-kr`에 있습니다. 이 저장소는 그와 겹치지 않는 **버전 2 시안**입니다.

## 열어 보기
`index.html` 파일 하나로 동작합니다. 내려받아 더블클릭하면 열립니다. (글꼴은 인터넷 연결 시 불러옵니다.)
체험 계정: 로그인 화면에서 지부장 / 지회장 / 경기복지회장 중 하나를 누르세요.

## 원본 골격
- 왼쪽: 로그인 상자 + 세로 6개 메뉴 (원본 메뉴 이름·순서 그대로)
- 가운데: 배너 → 공지사항 → 최신복지뉴스 → 포토갤러리
- 오른쪽: 달력 · 협력기관 4곳 · 교육 포스터
- 위: HOME · 회원가입 · 회원정보수정 · 로그인 · 검색

## 새로 얹은 기능 (화면에 NEW 표시)
- 내 지역 찾기, 전국시도복지회(지부 찾기), 지부별 방(소식·행사·사진·기사·안내)
- 지부장·지회장 화면: 회원 관리, 가입 승인, 행사, 사진·소식, 문의함, 지부 안내 편집, 서류 제출, 간사 권한, 활동 기록
- 시·도복지회장 화면: 소속 지부 현황, 2차 승인
- 행사·사진·응답 속도를 반영한 활동 점수와 배지
- 회원가입 신청이 선택한 지부의 지부장 승인함으로 전달됨

## 데이터 구분
- **실제**: 복지회 이름·로고·주소·연락처, 공지사항·최신복지뉴스 목록, 설립·사업·후원 안내, 교육 포스터
- **예시(가상)**: 지부별 회원·행사·점수·사진·기사·승인 신청·문의, 지부장·간사 이름. 화면 상단에 시안 표시가 있습니다.
- 실제 회원 정보와 개인정보는 들어 있지 않습니다. 회원 화면은 장애 유형·등급 같은 민감정보를 표시하지 않는 설계입니다.

## 검증
헤드리스 브라우저로 자동 검사 52개를 통과했습니다. 링크 2,210개가 유효하고 실제 클릭 1,538회가 모두 이동했습니다.
업무 흐름(승인·반려·문의 답변·참석 입력·사진 승인·간사 권한·지부 안내 수정·가입 신청 연결·검색·달력·권한 차단)도 포함됩니다.

## 알려진 제한
- 실제 휴대폰 단말 확인 전입니다.
- 포토갤러리 사진은 예시 그림입니다. 원본 사진을 옮기면 대체합니다.
- 협력기관 중 '사회복지자원봉사인증센터' 연결 주소는 원본 주소 목록에서 추정한 것으로 확인이 필요합니다.
- 원본 공지 중 대표자 지위와 관련된 글은 시안에 넣지 않았습니다.
- 서버 기능(로그인·DB)은 없습니다. 모든 입력은 브라우저 안에서만 동작합니다.

## 구성
- `index.html` 완성본 (로고·포스터 포함, 단일 파일)
- `previews/` 화면 캡처 (원본 대 시안 비교 포함)
- `source/` 조립 전 소스 (`src.html` 본체, `layer.js`·`layer.css` 원본 골격 레이어)
