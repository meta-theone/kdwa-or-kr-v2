# 한국신체장애인복지회 홈페이지 개선 시안 (버전 2)

기존 홈페이지(kdwa.or.kr)의 **원본 골격을 그대로 유지**하고, 포털처럼 정돈한 화면과 전체 조직 관리 기능을 얹은 개선 시안입니다.

> 이 저장소는 **시안(견본)** 입니다. 한국신체장애인복지회의 공식 홈페이지가 아니며, 화면의 지부별 수치·회원·행사·점수는 모두 예시입니다.

## 열어 보기
**바로 보기: https://meta-theone.github.io/kdwa-or-kr-v2/**

`index.html` 파일 하나로 동작합니다. 내려받아 더블클릭하면 열립니다. (글꼴은 인터넷 연결 시 불러옵니다.)
로그인 화면에서 체험 계정 4개 중 하나를 누르세요: 지부장, 지회장, 경기복지회장(시·도), 중앙 사무국.
어디서든 `Ctrl+K`(또는 `Cmd+K`)로 빠른 이동을 열 수 있습니다.

## 원본 골격 (그대로 유지)
- 왼쪽: 로그인 상자 + 세로 6개 메뉴 (원본 메뉴 이름·순서 그대로)
- 가운데: 배너 → 공지사항 → 최신복지뉴스 → 포토갤러리
- 오른쪽: 달력 · 협력기관 4곳 · 교육 포스터
- 위: HOME · 회원가입 · 회원정보수정 · 로그인 · 검색

## 이번에 정돈한 화면 (포털형)
- 가운데 큰 검색창, 흰 카드와 얇은 선 중심의 정돈된 구역, 안내 배너(3장, 자동 넘김 없음), 자주 찾는 메뉴 6개, 규모 숫자 띠
- 라이트·다크 모드, 글자 크기 조절, 키보드 이동, 모바일 하단 메뉴

## 조직 관리 기능 (화면에 NEW 표시)
**중앙 사무국**
- 전국 현황: 활동 지부 비율 추이, 월별 가입 신청, 시·도별 활동 지도, 가입 승인 흐름(병목 확인), 주의가 필요한 지부
- 조직 관리: 중앙 → 시·도복지회 → 지부 트리 탐색과 검색
- 결재함: 가입 최종 확정, 서류 승인·반려, 지부장 교체
- 공지 발송: 대상(전국·시·도) 선택, 채널 선택, 지부별 읽음 현황, 읽지 않은 곳 재알림
- 권한 관리: 역할별 권한표(최소 권한 원칙), 변경 기록
- 자동화 규칙: 가입 지연·문의 미답변·회비 미납·활동 없음·휴면 정보 파기·행사 후 사진 안내
- 월간 리포트: 전국·시·도·지부 범위별 자동 요약과 권고, 복사

**시·도복지회장**: 소속 지부 현황, 2차 승인, 월간 리포트
**지부장·지회장**: 회원 관리(미납·휴면·최근 가입 목록, 안내 보내기), 가입 승인, 행사, 사진·소식(촬영 동의 확인), 문의함(AI 답변 초안 시안), 지부 안내 편집, 서류 제출, 간사 권한, 월간 리포트, 활동 기록
**공통**: 알림 센터(종), 빠른 이동(Ctrl+K), 활동 점수와 배지, 활동 기록
- 회원가입 신청은 선택한 지부의 지부장 승인함 → 시·도 → 중앙 확정으로 이어집니다.

## 30년 발자취·제휴 분석 (복지회소개 메뉴, NEW)
지난 30년 중앙회와 지회·지부의 사업과 업무제휴를 **공개된 기사·공문서**로 조사한 결과를 사이트 안에 넣었습니다.
- 개요, 사업 유형, 사례 찾기(유형·지역·판정·검색 필터), 지역·연도, 조사 공백, 자료·방법의 여섯 구역
- 사례 49항목마다 실행 수준, 증거 수준, **확인되지 않은 것**, 출처 링크를 함께 표시
- 홈 화면의 30년 분석 구역과 4번째 배너, 전체 검색, Ctrl+K 빠른 이동, 중앙 사무국의 '30년 분석' 메뉴와 연결
- 표(CSV) 내려받기

조사 기준일 2026-10-07, 코덱스 리아(AI 조사 도구)가 작성한 **중간 조사**입니다. 전수조사가 아니며 표시 항목 수는 확정된 업무제휴 건수가 아닙니다.
검색어 92개, 후보 주소 198개 가운데 근거를 검토한 51항목 중 **49항목**만 공개 표시했습니다.
개인 후원자 이름이 들어 있던 1항목과 원문 전체를 아직 대조하지 못한 1항목은 제외했고, 내부 검토용 판단은 싣지 않았습니다.
## 데이터 구분
- **실제**: 복지회 이름·로고·주소·연락처, 공지사항·최신복지뉴스 목록, 설립·사업·후원 안내, 교육 포스터
- **예시(가상)**: 지부별 회원·행사·점수·사진·기사·승인 신청·문의·알림, 이름들. 화면 상단에 시안 표시가 있습니다.
- 실제 회원 정보와 개인정보는 들어 있지 않습니다. 회원 화면은 장애 유형·등급 같은 민감정보를 표시하지 않는 설계입니다.

## 검증
헤드리스 브라우저로 자동 검사 67개를 모두 통과했습니다(`tests/test_v6.js`). 마지막 화면 정돈 뒤에는 30년 분석 검사 20개를 다시 통과했습니다.
링크 2,657개가 모두 유효하고 실제 클릭 1,961회가 모두 이동했습니다. 4개 역할의 모든 관리 메뉴, 승인 흐름(지부 → 시·도 → 중앙), 알림, 공지 발송, 권한 변경, 자동화 규칙, 리포트, 빠른 이동, 접근 차단이 포함됩니다.

## 알려진 제한
- 실제 휴대폰 단말 확인 전입니다.
- 포토갤러리 사진은 예시 그림입니다. 원본 사진을 옮기면 대체합니다.
- 협력기관 중 '사회복지자원봉사인증센터' 연결 주소는 원본 주소 목록에서 추정한 것으로 확인이 필요합니다.
- AI 답변 초안·공지 다듬기는 정해진 문구로 만든 시안이며 실제 AI 연결이 아닙니다. 알림톡·문자 발송도 시안입니다.
- 서버 기능(로그인·DB)은 없습니다. 모든 입력은 브라우저 안에서만 동작합니다.
